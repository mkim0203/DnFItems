## 모든 데이터 저작권은 던담, 네오플에 있습니다.

v1.1 개선
* 던담정보 수집하여 딜, 랭크 정보 제공
* 현재 착용중인 장비 제공
* 포인트 높은 장비 (*) 표시
* 정보 후 html 파일 생성후 > 자동실행 (기본 브라우저에 따라서 해당 브라우저로 실행됨)

* 실행창 ui 제공
* 획득 수치 chart 표시

* 캐릭터 이미지 표출 버그 수정
